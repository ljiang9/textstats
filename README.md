# textstats

给写作者的诚实文本分析：文本进，阅读统计出。纯 Python 标准库，本地运行，不联网。

## 快速开始

```bash
python3 -m textstats examples/article-zh.md
cat draft.md | python3 -m textstats --stdin
python3 -m textstats --diff v1.md v2.md   # 对比两个草稿
python3 -m textstats article.md --json    # 机器可读输出
```

## 输出什么

- **规模**：中文字符数、中文字符数、英文单词数、句子数、段落数
- **预计阅读时间**：中文按 400 字/分钟、英文按 200 词/分钟估算（行业常用均值，见"诚实说明"）
- **高频词**：中文用二元组频率（去停用字），英文用词频（去停用词）
- **最长句**：超过 80 字标"可能难读"
- **重复句**：精确重复的句子分组列出
- `--diff`：两稿对比——字数/词数/句子数变化，新增与删除的句子列表

## 诚实说明（局限）

- **中文没有真正的分词**：用的是"相邻汉字二元组"启发式，不是分词器。高频二元组能反映主题，但别把它当关键词抽取用。
- **停用字/词表是极简的**：只覆盖最常见的虚词，领域文本里可能仍有噪音进榜。
- **阅读速度是平均值**：400 字/分钟、200 词/分钟是行业常用估算，实际因人、因文本难度而异。
- **句子切分是标点启发式**：按 `。！？…?!` 切分，Markdown 标题、代码块里的标点会被如实计入——它分析的是原始文本，不是渲染后的文章。
- **重复句只认精确重复**：改一个字就不算重复，语义级去重要用 embedding 方案。

## 退出码

- `0`：正常
- `1`：输入为空 / 文件读失败
- `2`：参数错误（argparse）
